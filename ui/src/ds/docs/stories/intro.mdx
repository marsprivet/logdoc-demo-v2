# LogDoc Design System

The components, tokens and icons LogDoc's UI is built from. They live in this
repository under `ui/src/ds` and are ours to change: the system started as a
copy of SigNoz's open-source design system (see `ui/src/ds/NOTICE.md`), and
LogDoc depends on no SigNoz package.

## Layout

| Folder | What lives there |
| --- | --- |
| `ui/src/ds/components` | React components (Base UI / Radix based, CSS Modules) |
| `ui/src/ds/tokens` | Token sources (`tokens/*.json`), the generator, and the generated CSS/TS |
| `ui/src/ds/icons` | 1,600+ icon components (`import { Search } from '@ds/icons'`) |
| `ui/src/ds/styles.css` | Entry stylesheet: primitives, the LogDoc theme, fonts, reset |
| `ui/src/components` | LogDoc-specific components composed from the system |

## Use in the app

Import each component from its own folder, so the bundle only carries the
styles of what a screen uses:

```ts
import { Button } from '@ds/components/button';
import { Search } from '@ds/icons';
```

`main.tsx` loads `@ds/styles.css` before anything else, and `index.html` picks
the theme:

```html
<html lang="en" data-theme="logdoc" class="dark"></html>
```

## Change a token

Edit the JSON in `ui/src/ds/tokens/tokens/` and regenerate:

```sh
npm --prefix ui run tokens
```

- `color.json`: primitive palettes. LogDoc adds **Ember** (brand orange, `#ff4e0e` at 500) and **Graphite** (its dark greys).
- `semantic-tokens.json`: the themes. `logdoc` is LogDoc's; `default` is the original SigNoz theme, kept for comparison.

The **Palette** button in the toolbar switches every story between the two.
